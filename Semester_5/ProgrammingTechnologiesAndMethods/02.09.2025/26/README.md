# Решение Задания 26 (из ЕГЭ)

Этот проект содержит решение задачи №26 по курсу "Технологии и методы программирования", а также полный набор тестов для проверки его корректности.

## Условие Задачи

> При онлайн-покупке билета на концерт известно, какие места в зале уже заняты. Необходимо купить два билета на такие соседние места в одном ряду, чтобы перед ними все кресла с такими же номерами во всех рядах были свободны, а ряд находился как можно дальше от сцены. Если в этом ряду таких пар мест несколько, найдите пару с наибольшими номерами мест. Нумерация рядов и мест ведётся с 1. Гарантируется, что хотя бы одна такая пара в зале есть. Определите наибольший номер ряда и наибольший номер места для найденной пары мест.
>
> Входные данные представлены в файле 26.txt следующим образом. В первой строке входного файла находятся три числа: N – количество занятых мест в зале (целое положительное число, не превышающее 10000), М – количество рядов (целое положительное число, не превышающее 100 000) и К – количество, мест в каждом ряду (целое положительное число, не превышающее 100 000). В следующих N строках находятся пары натуральных чисел: номер ряда и номер места занятого кресла соответственно (первое число не превышает значения М, а второе - К).
>
> Запишите в ответе два целых числа: искомый номер ряда и наибольший номер места в найденной паре.
>
> **Пример входного файла:**
> ```
> 7 7 8
> 1 1
> 6 6
> 5 5
> 6 7
> 4 4
> 2 2
> 3 3
> ```
> Условию задачи удовлетворяют места 7 и 8 в ряду 5: перед креслами 7 и 8 нет занятых мест и это последняя из двух возможных пар в этом ряду. В рядах 6 и 7 искомую пару найти нельзя. **Ответ: 5 8.**

## Структура Проекта

*   `main.py`: Основной скрипт для запуска решения.
*   `1_test.py`: Файл с модульными и интеграционными тестами для `main.py` с использованием `pytest`.

## Описание Алгоритма

Решение использует оптимизированный алгоритм, сложность которого не зависит от общего количества рядов в зале (M), что критически важно для больших входных данных.

1.  **Предобработка (O(N)):** Все занятые места считываются в `set` для быстрой проверки. Одновременно для каждой колонки вычисляется минимальный номер ряда, в котором есть занятое место.
2.  **Поиск (O(K)):** Вместо перебора всех рядов, алгоритм итерируется по всем возможным парам соседних *колонок* `(p, p+1)`.
3.  **Определение кандидата:** Для каждой пары колонок вычисляется максимально возможный ряд для решения (на основе данных предобработки).
4.  **Проверка и выбор:** Проверяется только одна пара мест в этом ряду-кандидате. Найденное решение сравнивается с лучшим из уже найденных по условиям задачи (сначала по номеру ряда, затем по номеру места).

Такой подход обеспечивает сложность O(N + K) и гарантирует быстрое выполнение даже на файлах с огромным количеством рядов.

## Использование

Для запуска решения необходимо передать путь к файлу с данными в качестве аргумента командной строки. Файл `26.txt` находится в родительской директории.

```bash
python main.py ../26.txt
```

## Тестирование

Проект содержит полный набор тестов, проверяющих корректность логики, обработку всех ошибок и пограничные случаи.

### Установка зависимостей

```bash
pip install pytest pytest-cov
```

### Запуск тестов

Для запуска всех тестов выполните команду:
```bash
pytest
```

### Анализ покрытия кода тестами

Чтобы запустить тесты и получить отчет о покрытии, используйте команду:
```bash
pytest --cov=main --cov-report term-missing
```
Ожидаемый результат — **100%** прохождение всех тестов (`11 passed`) и покрытие кода логики на уровне **98-100%**.
