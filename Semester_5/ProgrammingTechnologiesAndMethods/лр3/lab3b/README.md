# Security Scanner (Локальная версия)

Эта утилита является частью лабораторной работы №3 по курсу "Технологии и методы программирования".

## Описание

`SecurityScanner_Local.exe` — это программа для ОС Windows, которая:
1.  Собирает подробную системную информацию о компьютере (ЦП, ОЗУ, ОС, диски, сеть и т.д.).
2.  Отправляет собранные данные по локальной сети в заранее настроенную общую папку (SMB share).

Данные сохраняются в директорию с именем `ИмяКомпьютера-ИмяПользователя` для удобной идентификации.

## Сборка

1.  Установите необходимые зависимости:
    ```bash
    pip install psutil pyinstaller
    ```
2.  Откройте файл `collector.py` и укажите правильный `NETWORK_SHARE_PATH`.
3.  Запустите сборку:
    ```bash
    pyinstaller --onefile --noconsole --name SecurityScanner_Local --icon="icon.ico" collector.py
    ```

## Настройка сервера (хост-машины)

Для корректной работы анонимного (гостевого) доступа на современных ОС Windows требуется включение устаревшего протокола SMBv1.

> [!WARNING]
> **Внимание!** Включение SMBv1 открывает критические уязвимости в безопасности системы. Данный шаг необходим **исключительно для демонстрации** в рамках изолированной учебной сети.

Для включения SMBv1 выполните в командной строке от имени администратора:
```cmd
dism /online /enable-feature /featurename:SMB1Protocol
```
После выполнения команды потребуется перезагрузка компьютера.

> [!IMPORTANT]
> **Настоятельно рекомендуется отключить SMBv1 сразу после завершения тестирования**, чтобы восстановить уровень безопасности системы. Для отключения выполните команду:
> ```cmd
> dism /online /disable-feature /featurename:SMB1Protocol
> ```
> (также потребуется перезагрузка).
