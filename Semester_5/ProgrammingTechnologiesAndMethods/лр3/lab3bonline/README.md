# Security Scanner (Веб-версия)

Эта утилита является частью лабораторной работы №3 по курсу "Технологии и методы программирования".

## Описание

`SecurityScanner_Web.exe` — это программа для ОС Windows, которая:
1.  Собирает подробную системную информацию о компьютере (ЦП, ОЗУ, ОС, диски, сеть и т.д.).
2.  Отправляет собранные данные по протоколу HTTP на удаленный веб-сервер для централизованного хранения и просмотра.

Серверная часть реализована на Flask и развернута на PythonAnywhere.

## Сборка

1.  Установите необходимые зависимости:
    ```bash
    pip install psutil pyinstaller requests
    ```
2.  Откройте файл `collector.py` и убедитесь, что `SERVER_URL` указывает на правильный API-эндпоинт.
3.  Запустите сборку:
    ```bash
    pyinstaller --onefile --noconsole --name SecurityScanner_Web --icon="icon.ico" collector.py
    ```
