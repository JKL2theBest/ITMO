# Лабораторная работа №2: Программа с системой защиты
Пример реализации консольной утилиты с триальной версией на Python.

## Описание
Разработана консольная утилита, которая запрашивает ФИО пользователя и сохраняет его в файл. Программа оснащена системой защиты, ограничивающей ее использование по времени и количеству запусков.

## Основные возможности
-   **Запрос ФИО** пользователя с пошаговой валидацией ввода.
-   **Сохранение данных** в общий для всех пользователей файл (`C:\ProgramData\Lab2App\users.txt`).
-   **Проверка на дубликаты** ФИО перед записью.
-   **Двойная система лицензирования (триал-версия):**
    -   Ограничение по количеству запусков (`5 запусков`).
    -   Ограничение по времени использования (`3 минуты` с момента первого запуска).
-   **Защита от переустановки:** состояние триала хранится в реестре Windows (`HKEY_CURRENT_USER\Software\Lab2ProtectionApp_PY_Fixed`) и не удаляется при деинсталляции.
-   **Полный пакет для дистрибуции:** инсталлятор и деинсталлятор, корректно регистрирующие программу в системе.

## Стек технологий
-   **Язык:** Python 3
-   **Тестирование:** Pytest, Pytest-mock, Pytest-cov (с **100% покрытием** кода).
-   **Сборка `.exe`:** PyInstaller
-   **Создание инсталлятора:** Inno Setup
-   **Хранение данных триала:** Реестр Windows (через модуль `winreg`).

## Инструкция разработчика

### 1. Установка зависимостей
```bash
pip install pytest pytest-mock pytest-cov pyinstaller
```

### 2. Запуск тестов
Для проверки корректности логики и получения отчета о покрытии:
```bash
pytest --cov=lab_app
```

### 3. Сборка `.exe` файла
```bash
pyinstaller --onefile lab_app.py --name main
```
Готовый `.exe` появится в папке `dist`.

### 4. Сборка инсталлятора
1.  Установите [Inno Setup](https://jrsoftware.org/isinfo.php).
2.  Откройте файл `installer_script.iss` в Inno Setup Compiler.
3.  Нажмите "Compile" (F9). Готовый `lab2_setup.exe` будет создан в указанной в скрипте папке.
