# Файловый Протектор (Лабораторная работа 1а (python))

Профессиональная утилита для защиты файлов и папок в среде Windows. Программа запрещает создание, копирование, удаление или переименование файлов по заданным шаблонам, используя встроенные механизмы безопасности Windows.

Проект демонстрирует применение ключевых технологий программирования: **объектно-ориентированного подхода**, **модульной архитектуры** и **создание гибридных (CLI+GUI) приложений** с корректной обработкой системных вызовов Windows.

## Ключевые возможности

-   **Надежная защита:** Использует списки контроля доступа Windows (DACL) для установки явного запрета на доступ (`GENERIC_ALL` для `Everyone`), который не может обойти даже администратор.
-   **Гибкая настройка:** Список защищаемых файлов и масок задается в простом текстовом файле `template.tbl`.
-   **Защита паролем:** Отключение защиты требует ввода пароля, который хранится в хешированном виде с использованием криптографической соли (`sha256(salt + password)`).
-   **Режим "Стража":** Автоматически защищает новые и переименованные файлы, соответствующие шаблонам, в реальном времени.
-   **Единый исполняемый файл:** Программа представляет собой один `.exe` файл, который может работать в двух режимах.
    -   Удобный **графический интерфейс (GUI)** для повседневного использования.
    -   Мощный **интерфейс командной строки (CLI)** для автоматизации и скриптов.

## Установка

1.  Поместите исполняемый файл `protector.exe` в папку, файлы в которой вы хотите защищать.
2.  Запустите командную строку (`cmd.exe`) в этой папке.
3.  Выполните команду первоначальной настройки:

    ```bash
    protector.exe setup
    ```
4.  Программа попросит вас создать и подтвердить пароль. Этот пароль будет необходим для отключения защиты.
5.  После выполнения команды в папке появится файл `template.tbl`.

## Использование

Программа требует прав администратора для работы и будет запрашивать их автоматически.

### Графический интерфейс (GUI)

Для запуска просто дважды щелкните по файлу `protector.exe`.

-   **Индикаторы состояния:** Наглядно показывают, включен ли "Файловый щит" (защита) и "Режим стража" (слежение).
-   **АКТИВИРОВАТЬ ЗАЩИТУ:** Применяет защиту ко всем существующим файлам по шаблонам и запускает фоновый процесс слежения.
-   **ОТКЛЮЧИТЬ ВСЁ:** Запрашивает "пароль смотрителя", отключает защиту со всех файлов и останавливает процесс слежения.
-   **Открыть журнал событий:** Открывает панель, где отображаются все действия программы в реальном времени.

### Командная строка (CLI)

Все команды выполняются из командной строки в папке с программой.

-   **Показать справку (не требует прав администратора):**
    ```bash
    protector.exe --help
    ```
-   **Первоначальная настройка:**
    ```bash
    protector.exe setup
    ```
-   **Сброс настроек (если защита включена):**
    ```bash
    protector.exe setup
    ```
    Программа попросит ввести код подтверждения `12345` для сброса защищенной конфигурации.
-   **Проверить статус защиты:**
    ```bash
    protector.exe status
    ```
-   **Включить защиту:**
    ```bash
    protector.exe on
    ```
-   **Отключить защиту (потребуется ввод пароля):**
    ```bash
    protector.exe off
    ```
-   **Включить режим постоянного слежения:**
    ```bash
    protector.exe watch
    ```
    (Для остановки нажмите `Ctrl+C`)

## Конфигурация (`template.tbl`)

Это текстовый файл, который вы можете редактировать вручную для управления списком защищаемых файлов.

-   **Первая строка:** Содержит служебную информацию (соль и хеш пароля). **Не изменяйте эту строку вручную!**
-   **Остальные строки:** Шаблоны (маски) файлов для защиты.
    -   Каждый шаблон указывается на новой строке.
    -   Пустые строки и строки, начинающиеся с `#`, игнорируются.
    -   Поддерживаются стандартные маски: `*` (любое количество символов) и `?` (один любой символ).

#### Пример `template.tbl`:
```
# Первая строка сгенерирована автоматически, не трогайте ее
YTczNDU..._salt_...NzY2Zj==:a1b2c3d4..._hash_...e5f6

# --- Шаблоны защищаемых файлов ---
# Каждая строка - это маска файла (например, *.docx, report_?.doc, secret.txt)
# Пустые строки и строки, начинающиеся с #, игнорируются.

secret_document.txt
report_*.docx
*.log
finances_202?.xlsx
```
