# Реализация исторических алгоритмов шифрования

Программа с графическим интерфейсом (GUI) для демонстрации работы двух классических перестановочных шифров: **Скитала** и **Решётка Кардано**.

Проект выполнен в рамках учебного курса "Технологии и методы программирования" с упором на качество кода, документирование, соответствие требованиям ТЗ и реализацию "креативных" возможностей для улучшения пользовательского опыта.

### Основные возможности

*   **Графический интерфейс:** Реализован на стандартной библиотеке `tkinter` с кастомной темной темой для комфортной работы.
*   **Два алгоритма шифрования:** Полная реализация шифрования и дешифрования для шифров Скитала и Решётка Кардано.
*   **Работа с файлами:** Поддержка открытия текстовых файлов для шифрования и сохранения результата в файл.
*   **Интерактивные функции для наглядности:**
    *   **Визуализация решётки Кардано:** При каждой операции в дочернем окне наглядно отображается сгенерированная решётка-ключ.
    *   **Анимация процесса шифрования Скиталы:** Отдельное окно демонстрирует пошаговый процесс записи текста в матрицу и его считывания для получения шифротекста.
*   **Пользовательские удобства:**
    *   Встроенные примеры для быстрой демонстрации работы каждого шифра.
    *   Справочная информация по каждому алгоритму, доступная через меню.
    *   Контекстное меню (Копировать/Вставить/Вырезать) по правому клику мыши.

### Реализованные алгоритмы

1.  **Шифр Скитала (Scytale Cipher)**
    *   **Принцип:** Имитация наматывания ленты с текстом на цилиндр.
    *   **Ключ:** Целое число (диаметр цилиндра).
    *   **Особенности:** Простая, быстрая, но крайне неустойчивая к анализу перестановка.

2.  **Решётка Кардано (Cardan Grille)**
    *   **Принцип:** Перестановка символов с помощью трафарета (решётки), который последовательно поворачивается на 90 градусов.
    *   **Ключ:** Ключевое слово (для детерминированной генерации решётки) и размер решётки.
    *   **Особенности:** Текст дополняется символом `_` до нужной длины. Безопасность зависит от секретности ключевого слова.

### Требования к окружению

*   **Python 3.7+** (рекомендуется 3.9 и выше).
*   Внешние библиотеки **не требуются**. Все реализовано с использованием стандартной библиотеки Python.

### Запуск и использование

1.  Поместите файлы `app.py` и `ciphers.py` в одну директорию.
2.  Откройте терминал или командную строку в этой директории.
3.  Выполните команду:
    ```bash
    python app.py
    ```
4.  В открывшемся окне выберите шифр, введите текст и ключ, после чего нажмите "Шифровать" или "Дешифровать".
5.  Используйте меню "Файл" для работы с файлами, "Примеры" для загрузки готовых данных и "Справка" для получения информации об алгоритмах.

### Сборка `.exe` файла (для Windows)

Для создания одного исполняемого файла, который не требует установки Python, можно использовать `PyInstaller`.

1.  **Установите PyInstaller:**
    ```bash
    pip install pyinstaller
    ```
2.  **Выполните команду сборки** в терминале, находясь в папке с файлами проекта:
    ```bash
    pyinstaller --onefile --windowed --name=HistoricalCiphers app.py
    ```
    *   `--onefile`: Упаковать все в один исполняемый файл.
    *   `--windowed`: Не показывать консоль при запуске приложения.
    *   `--name`: Задать имя для `.exe` файла.

3.  Готовый `HistoricalCiphers.exe` будет находиться в созданной папке `dist`.

### Структура проекта

Проект сознательно разделен на два файла для соблюдения принципа разделения ответственности (Separation of Concerns):

*   `ciphers.py`: **Модуль бизнес-логики.** Содержит только "чистые" функции для шифрования, дешифрования и генерации ключей. Не зависит от интерфейса.
*   `app.py`: **Главный модуль приложения.** Отвечает за весь графический интерфейс (GUI), обработку событий от пользователя и вызов функций из модуля `ciphers.py`. Является точкой входа.
