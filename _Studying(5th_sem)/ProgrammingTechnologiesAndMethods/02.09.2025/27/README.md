# Решение Задания 27 (из ЕГЭ)

Этот проект содержит решение задачи №27 по курсу "Технологии и методы программирования", скрипт для визуализации результатов и полный набор тестов.

## Условие Задачи

> При проведении эксперимента заряженные частицы попадают на чувствительный экран размером 12 на 9 условных единиц. При попадании каждой частицы на экран в протоколе фиксируются координаты попадания в условных единицах. При анализе результатов выделяют кластеры – группы точек на экране, в которые попали частицы. Каждая точка принадлежит только одному кластеру. Минимальное (максимальное) расстояние между кластерами – это минимальное (максимальное) расстояние между двумя точками, одна из которых принадлежит одному кластеру, а вторая – другому. Расстояние между двумя точками A(x1, y1) и B(x2, y2) вычисляется по формуле:
> `d(A,B) = sqrt((x1-x2)^2 + (y1-y2)^2)`
>
> Аномалиями назовём совокупности из не более чем 10 точек, каждая из которых находится на расстоянии более одной условной единицы от точек кластеров. Аномалии в расчётах не учитываются. Даны два входных файла 27a.txt и 27b.txt). В файле `27a.txt` хранятся данные о звёздах **двух кластеров**. В каждой строке записана информация о расположении на карте одной точки: сначала координата x, затем координата y (в условных единицах). Известно, что количество точек не превышает 1000. В файле `27b.txt` хранятся данные о **трёх кластерах**. Известно, что количество точек не превышает 10 000. Структура хранения информации о точках в файле 27b.txt аналогична файлу 27a.txt.
>
> Для каждого файла определите минимальное `dmin` и максимальное `dmax` расстояния между двумя кластерами. В ответ запишите 4 числа: в первой строке целую часть произведения `dmin × 10 000`, затем целую часть произведения `dmax × 10 000` для файла `27a.txt`, в третьей и четвертой строке – аналогичные данные для файла `27b.txt`.

## Структура Проекта

*   `main.py`: Основной скрипт для запуска решения.
*   `clusters.py`: Скрипт для наглядной визуализации результатов кластеризации.
*   `2_test.py`: Файл с модульными и интеграционными тестами с использованием `pytest`.

## Описание Алгоритма

Решение построено на базе библиотеки `scikit-learn` и использует алгоритм кластеризации **DBSCAN**, который идеально подходит для этой задачи, так как автоматически определяет шумовые точки (аномалии).

Ключевые параметры DBSCAN были подобраны строго на основе ТЗ:
*   `eps=1.0`: Максимальное расстояние между точками для их объединения в кластер, взято из условия "на расстоянии более одной условной единицы".
*   `min_samples=11`: Минимальное количество точек для формирования ядра кластера. Выбрано из условия "аномалиями назовём совокупности из не более чем 10 точек". Это гарантирует, что группы до 10 точек не будут считаться полноценным кластером.

После кластеризации программа проверяет, что количество найденных кластеров совпадает с ожидаемым (2 для `27a.txt`, 3 для `27b.txt`), и затем вычисляет минимальные и максимальные расстояния между ними.

## Использование

### Зависимости
Для работы всех скриптов необходимы библиотеки:
```bash
pip install numpy scikit-learn scipy matplotlib pytest
```

### Запуск основного решения
Скрипт принимает пары аргументов: `[путь_к_файлу]` и `[ожидаемое_число_кластеров]`. Файлы данных находятся в родительской директории.

```bash
python main.py ../27a.txt 2 ../27b.txt 3
```

### Визуализация Кластеров
Скрипт `clusters.py` (вероятно, ваш `visualize.py`) позволяет наглядно увидеть результат работы алгоритма.

```bash
# Для файла A
python clusters.py ../27a.txt

# Для файла B
python clusters.py ../27b.txt
```

### Тестирование
Для проверки корректности и надежности кода выполните:
```bash
pytest
```
Для получения отчета о покрытии кода тестами:
```bash
pytest --cov=main --cov-report term-missing
```
