# System Info Protector

Проект для создания и верификации файла `sys.tat` с системной информацией, защищенной цифровой подписью.

## Компоненты

*   `installer.py`: GUI-инсталлятор, который собирает системную информацию, генерирует RSA-ключи, подписывает данные и устанавливает все компоненты.
*   `secur.py`: Программа-верификатор, которая проверяет цифровую подпись файла `sys.tat` при его открытии.

## Сборка

1.  **Установите зависимости:**
    ```bash
    pip install psutil cryptography pyinstaller
    ```

2.  **Поместите `installer.py` и `secur.py` в одну папку.**

3.  **Соберите `secur.exe`:**
    ```bash
    pyinstaller --onefile --windowed --name secur secur.py
    ```

4.  **Соберите `sys_doc.exe` (инсталлятор):**
    ```bash
    pyinstaller --onefile --windowed --name sys_doc installer.py
    ```

5.  **Подготовьте к запуску:**
    *   Перейдите в созданную папку `dist`.
    *   Убедитесь, что `sys_doc.exe` и `secur.exe` находятся в одной директории.

## Использование

1.  Запустите `sys_doc.exe`.
2.  Выберите папку и нажмите "Установить".
3.  После установки программа проверки `secur.exe` запустится автоматически.
4.  Введите фамилию (`Suhangulyyev`), чтобы проверить подпись.
5.  В дальнейшем для проверки можно просто дважды кликнуть по файлу `sys.tat` в папке установки.
