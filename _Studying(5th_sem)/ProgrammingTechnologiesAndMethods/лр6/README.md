# Система Аутентификации и Авторизации (Лабораторная работа №6)

## Описание

Данный проект представляет собой консольную реализацию простой, но надежной системы аутентификации и авторизации пользователей в соответствии с ТЗ лабораторной работы №6 по курсу "Технологии и методы программирования".

Система демонстрирует применение многоуровневой архитектуры, современных практик безопасности и принципов чистого кода.

## Технологический стек

-   **Язык:** Python 3.11+
-   **База данных:** SQLite (через `aiosqlite`)
-   **ORM:** SQLAlchemy 2.0 (асинхронный режим)
-   **Хеширование паролей:** Argon2id (через `passlib`)
-   **Валидация данных:** Pydantic
-   **Тестирование:** Pytest, Pytest-asyncio

## Архитектура

Проект построен на основе многоуровневой архитектуры для четкого разделения ответственности:

-   `main.py`: Слой представления (консольный интерфейс).
-   `services/`: Слой бизнес-логики (регистрация, вход, авторизация, управление сессиями).
-   `db/repository.py`: Слой доступа к данным (инкапсуляция SQL-запросов).
-   `db/models.py`: Слой моделей данных (описание таблиц БД через SQLAlchemy).
-   `core/`: Вспомогательные модули (безопасность, конфигурация).
-   `schemas/`: Схемы Pydantic для валидации данных.

## Функциональность

-   Регистрация новых пользователей с ролями `user` или `admin`.
-   Безопасное хранение паролей с использованием Argon2id и уникальной соли для каждого пароля.
-   Аутентификация пользователей по имени и паролю.
-   Управление сессиями на основе токенов, хранящихся в базе данных. Сессии имеют ограниченный срок действия (1 час).
-   Авторизация на основе ролей. Реализована простая иерархия: `admin` имеет доступ ко всем ресурсам, `user` — только к общим.
-   Корректный выход из системы с удалением сессии из БД.

## Запуск и использование

### 1. Требования

-   Python 3.11+
-   `venv` для создания виртуального окружения

### 2. Установка

```bash
# 1. Клонируйте или скачайте репозиторий и перейдите в его папку
# (в вашем случае, это папка лр6)

# 2. Создайте и активируйте виртуальное окружение
python -m venv venv
# Windows:
# venv\Scripts\activate
# macOS/Linux:
# source venv/bin/activate

# 3. Установите зависимости
pip install -r requirements.txt
```

### 3. Запуск тестов

Для проверки корректности работы модулей (хеширование, бизнес-логика) можно запустить тесты:

```bash
# Находясь в корневой папке проекта (лр6)
pytest
```

### 4. Запуск приложения

```bash
# Находясь в корневой папке проекта (лр6)
python main.py
```

После запуска приложение выведет список доступных команд: `register`, `login`, `logout`, `access <resource>`, `exit`.
