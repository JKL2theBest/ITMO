# Файловый Протектор (Лабораторная работа 1а)

Исходный код программы на Python для защиты файлов в директории Windows с использованием ACL и файлового наблюдателя.

## Структура проекта

*   `protector.py`: Консольное ядро программы с основной логикой (`setup`, `on`, `off`, `status`, `watch`).
*   `gui.py`: Графический интерфейс (GUI) на Tkinter, управляющий `protector.py`.

## Сборка `.exe` из исходного кода

### 1. Установка зависимостей

Для работы и сборки проекта необходимы следующие библиотеки:
```bash
pip install pywin32 watchdog pyinstaller
```

### 2. Компиляция

Проект состоит из двух частей, которые компилируются отдельно.

**А. Сборка консольного ядра (`Protector.exe`):**
```bash
pyinstaller --onefile --name Protector protector.py
```

**Б. Сборка GUI (`ProtectorGUI.exe`):**
```bash
pyinstaller --onefile --windowed --name GUI gui.py
```
*   `--windowed`: Ключевой флаг для скрытия консоли у GUI-приложения.

После выполнения команд готовые `.exe` файлы появятся в папке `dist`.

## Использование скомпилированного приложения

1.  Скопируйте `Protector.exe` и `ProtectorGUI.exe` из папки `dist` в одну рабочую директорию.
2.  **Первоначальная настройка (обязательно):** Запустите `Protector.exe setup` из командной строки и задайте пароль. Будет создан файл `template.tbl`.
3.  **Запуск GUI:** Запустите `ProtectorGUI.exe` двойным кликом. Интерфейс позволяет включать/выключать защиту и слежение, а также просматривать логи.

**Примечание:** Программа автоматически запрашивает права Администратора при запуске, так как они необходимы для изменения прав доступа к файлам.
