# Файловый Протектор (Лабораторная работа 1а)

Программа на PowerShell для защиты файлов в директории по заданным шаблонам с использованием пароля. Реализована как в виде консольной утилиты, так и в виде GUI-приложения.

## Структура проекта

*   `protector.ps1` — ядро программы с основной логикой.
*   `gui.ps1` — графический интерфейс (GUI) для управления.
*   `start.bat` — запускатор для консольной версии.
*   `start_gui.bat` — запускатор для GUI-версии.

## Быстрый старт

### 1. Первоначальная настройка (нужно сделать один раз)

Запустите `start.bat setup` в командной строке и задайте пароль.
```bash
start.bat setup
```

### 2. Использование GUI (рекомендуется)

Просто запустите файл `start_gui.bat` двойным кликом.

*   **ВКЛЮЧИТЬ ВСЕ** — применяет защиту к существующим файлам и активирует слежение за новыми.
*   **ВЫКЛЮЧИТЬ ВСЕ** — запрашивает пароль и снимает все виды защиты.

### 3. Использование через командную строку

Для управления программой используйте `start.bat` с одной из команд:

*   `start.bat on` — включить защиту для существующих файлов.
*   `start.bat off` — выключить защиту (запросит пароль).
*   `start.bat status` — проверить текущий статус.
*   `start.bat watch` — запустить режим слежения за новыми файлами.

**Важно:** Для работы программы требуются права Администратора. Скрипты автоматически запросят их при запуске.
